# Warito Racing Club — Responsive V1

Sitio estático responsive, listo para publicar en Vercel. Sin framework, sin dependencias, sin build.

## Deploy en Vercel

1. Importar este repositorio de GitHub.
2. Framework Preset: **Other**.
3. Root Directory: **./**.
4. Build Command: dejar vacío.
5. Output Directory: dejar vacío (Vercel sirve el directorio raíz).
6. Deploy.

## Arquitectura
- `index.html`: contenido y SEO.
- `styles.css`: diseño responsive para móvil, tablet y desktop.
- `script.js`: menú móvil, fichas de servicios, proyecto, scroll y animaciones.
- `vercel.json`: cabeceras de seguridad y caché básica.
